# Organ Donor Assessment in the ICU: virtual simulation game

Playable WebGL build of a nursing-education simulation (Level 1: Recognize, Refer, Support; Level 2: Determine, Manage, Collaborate).
Play it at the GitHub Pages link for this repository. Best in a recent desktop Chrome, Edge, Firefox or Safari.
